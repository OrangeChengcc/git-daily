## 👀 好项目很多，下一站去哪？

想搭建个人知识库，却不知道从哪个项目开始；想试试本地大模型，搜索框里又只有几个模糊的关键词；收藏了不少仓库，下次需要时却想不起名字。

**GitDaily 是一个面向开发者与技术爱好者的开源项目发现站。** 把每日推荐、自然语言搜索、GitHub 趋势榜和个人收藏放在一起，让发现、了解、收藏连成一次顺手的体验。

今天没有明确目标？翻几张推荐卡片。已经有了想法？直接把需求写进搜索框。

## 🧭 你可以在这里做什么

| | 功能 | 发现的方式 |
| :---: | --- | --- |
| 🗓️ | **每日推荐** | 默认每天 10 个项目，卡片式逐个浏览，也能通过日历回看往期推荐。 |
| 🔎 | **自然语言搜索** | 输入需求或项目名，在站内项目库中结合关键词与语义查找。 |
| 🔥 | **GitHub Trending** | 切换今日、本周、本月榜单，查看 GitHub 官方趋势项目与对应增长量。 |
| 🏆 | **GitHub Top100** | 浏览 GitHub 全站公开仓库 Star 前 100，排名每周更新。 |
| ⭐ | **收藏与 Star 同步** | 使用 GitHub 登录，将 GitHub Star 同步到站内，也能在站内直接添加或取消 Star。 |
| 📖 | **项目详情** | 查看中文简介、README、语言、许可证等资料，再决定要不要深入了解。 |

## 🔎 不记得项目名，也可以开始搜索

试着描述你想做的事：

> 🧠 “我想搭建一个自托管的个人知识库”
>
> 🤖 “有没有能在本地运行大模型的工具？”
>
> 🌐 “我想做浏览器自动化”

也可以直接输入 `playwright` 这样的项目名。

搜索会结合项目名称、简介、Topics 与已收录的 README 内容理解需求，返回站内项目库中的相关项目。语义服务暂时不可用时，会切换为关键词搜索并提示。

💡 在搜索页按下 **⌘ K / Ctrl K** 或 **/**，即可聚焦搜索框。

## 🗓️ 每天来一次，给灵感留个位置

- **每天一份新发现**：默认北京时间 00:05 发布当天推荐，覆盖不同 Star 区间的项目。
- **少一点重复遇见**：推荐设有 30 天冷却期，给更多项目出场的机会。
- **随时回头看看**：通过日历翻阅已发布的往期推荐，找回那天让你眼前一亮的工具。
- **慢慢看，也很舒服**：支持明暗主题与移动端浏览，一张张翻阅，遇到喜欢的就收藏。

每日推荐由规则自动生成，同一天的名单与顺序固定；候选项目不足时，以实际发布数量为准。

## ⭐ 从“发现了”到“以后用得上”

**看看今日推荐 → 搜索感兴趣的方向 → 阅读项目详情 → 收藏到 GitHub。**

浏览推荐、搜索和榜单无需登录。需要收藏时，再使用 GitHub 账号登录。

站内收藏与 GitHub Star 联动：**在 GitDaily 添加或取消收藏，也会在 GitHub 添加或取消对应仓库的 Star。** 已有 GitHub Star 也可以同步到站内，集中浏览。
